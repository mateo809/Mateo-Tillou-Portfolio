Ma démarche

De l’idée à l’écran livré

  1. Comprendre

    J’échange avec le client et l’équipe pour cerner les besoins et les usages.

  2. Organiser

    Je structure les idées et les parcours sur Miro, et je les documente.

  3. Concevoir

    Wireframes puis maquettes dans Figma, pensées pour tous les écrans.

  4. Intégrer

    Je code moi-même l’interface, en web ou dans Unity, fidèle à la maquette.
