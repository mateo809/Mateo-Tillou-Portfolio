# Portfolio — Matéo Tillou, UI/UX Designer

🌐 **https://mateo809.github.io/Mateo-Tillou-Portfolio/**

Portfolio personnel : projets web et jeu vidéo, démarche de conception et contact.

## Stack

Site statique, sans framework ni étape de build :

- `index.html` : une seule page, sémantique et accessible (navigation au clavier, lien d’évitement, contrastes AA)
- `assets/css/style.css` : design tokens en variables CSS, mise en page responsive (mobile → desktop), `prefers-reduced-motion` respecté
- `assets/fonts/` : Bricolage Grotesque et DM Sans auto-hébergées (licence SIL OFL 1.1)
- Métadonnées Open Graph et données structurées schema.org pour un bel aperçu sur LinkedIn

## Lancer en local

```bash
python3 -m http.server 8000
# puis ouvrir http://localhost:8000
```

## Mise en ligne

Hébergé avec GitHub Pages depuis la branche `main` (dossier racine).
